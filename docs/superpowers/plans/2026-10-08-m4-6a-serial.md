# M4.6a The Serial Code in C — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the firmware's serial code (the receive and host-line interrupts, the receive path, the immediate commands and the reply output; 18 hooked routines and 2 handlers) to C and prove it against the ROM through `diff_lts`, a new probe-based differential test `diff_serial`, and the goldens.

**Architecture:**
- **Infrastructure first (Task 1).**
  - The firmware reads and writes every SFR through its host (`read_sfr` for all of $DA–$FF, new `write_sfr`, the `fw_sfr*` helpers with the CPU's read-modify-write).
  - A semantic wait seam, `fw_host.wait(FW_WAIT_UART_TX)`, which the hybrid host implements by running the ROM's `ser_tx_wait` loop at $C500.
  - Interrupt handlers become replacements (`isr` rows, exit by `machine_return_interrupt`).
  - `diff_lts` compares the SFR model state and handles `isr` rows; `ser_hex_chars` is converted; the suite `suite_fw_ser` is added.
- **The probe test before the C (Task 2).** `diff_serial` makes synthetic calls from real corpus states with injected changes (host line, parallel mode, the `_INT1` latch, ring page ends), proved ROM against ROM.
- **Then the C, leaves first.** The transmit side (Task 3), the receive side and the immediate commands (Task 4), the two ISRs (Task 5).
- **C calls C.** `isr_int1` → `ser_rx_byte` → `cmd_imm_match` → `cmd_match_table`, `ser_rx_flush_cmd`, `ser_rx_put`; `ser_tx_service` → `ser_tx_get`, `ser_tx_send`; `cmd_reply.c` and `par_play` call the C transmit routines directly.
- **What stays ROM.** `ser_tx_wait` $C500 (host code behind the wait seam), `isr_par_ready`/`isr_par_hold` and the speech-timing code (M4.6b), boot, the main loop and the banks (M4.6c).
- **Hooks.** 18 routines, giving 89 replacements and 90 `golden_hybrid` modes.

**Tech Stack:** C11 with MSVC 2022 (`build.bat`, `/W4 /WX`).

**Spec:** `docs/superpowers/specs/2026-10-08-m4-6a-serial-design.md` (M4.6a spec). Its foundations are:
- the M4.5 spec, `docs/superpowers/specs/2026-10-08-m4-5-frame-builder-design.md` (the latest conventions; §6 "As built");
- the M4.4b spec, `docs/superpowers/specs/2026-10-07-m4-4b-frame-loop-design.md` (`read_sfr`, `diff_play` and its injections, the bridge deadline; §6 "As built");
- the M4.2 spec, `docs/superpowers/specs/2026-10-03-m4-2-command-parser-design.md` (`cmd_match_table`, the handlers behind a C dispatcher, the reply handlers);
- the M4.0 spec, `docs/superpowers/specs/2026-10-03-m4-0-replacement-foundation-design.md` (§8 "As built").

**ROM facts checked / what was verified while proving the plan** (`src/cpu740/cpu740.c`, `src/machine/m50734.c`, `src/machine/machine.c`; `rom_C500_ser_tx_wait.txt`, `rom_C55A_ser_hex_digit.txt`, `rom_C571_ser_tx_hex.txt`, `rom_ABF0_boot_clear_input_state.txt`, `rom_AC22_boot_init_ports.txt`, `rom_AC68_boot_init_host_lines.txt`; the ROM image for the operand scans; everything below was run, nothing is copied from the spec):
- **How the CPU touches an SFR** (`cpu740.c`): `LDA`/`CMP`/`BBS`/`BBC zp` are one bus read; `STA` and `LDM #imm,zp` one bus write (`LDM` does not read); `SEB`/`CLB bit,zp` a bus read, then a bus write of the changed value (`M_SEB`/`M_CLB`). A port read returns its pins, `(port_in & ~dir) | (latch & dir)` (`m50734_port_pins`), so `SEB`/`CLB` on P0 copies an input pin's level into the latch. Hence `fw_sfr_seb`/`fw_sfr_clb` = `read_sfr` then `write_sfr`, and `fw_sfr_bit` = one `read_sfr`. `test_host_sfr` checks it on the emulator: P0 with P0.2 an input at level 1, `SEB5` writes $24 to the latch.
- **Read side effects** (`m50734_read`): `UART_RX` $E5 clears `uart_rx_full`; `UART_STATUS` $E7 is `$02 | full` and has no side effect (bits 2–4, the receive errors, are never set: the model has no error); `P1_LATCH` $F2 reads `port_in[1]`, and writing it (and `UART_RX`, `UART_STATUS`) is ignored; a write to `UART_TX` $E4 counts (`uart_tx_count`, `uart_tx_last`). So the hybrid host reads and writes through the bus, with these effects, which the ROM's own accesses have (spec §3.1); the old `read_sfr` refused every SFR but $E7 for exactly this reason.
- **`ser_tx_wait` $C500** is `37 E7 FD 60`: `BBC1 UART_STATUS,$C500` / `RTS`. Called by `JSR` at $C505 (`ser_tx_send`) and $C596 (`ser_tx_service`), nothing else; no relative branch reaches it. In the machine bit 1 is always set, so it returns after 11 cycles (`BBC1` not taken 5, `RTS` 6: `test_host_wait`). It is never hooked: the hybrid host runs it through `host_rom_call` (interrupts live, the bridge deadline), with the machine's own A, X and Y, which it does not change.
- **The interrupt entry and `RTI`** (`cpu740.c`): `take_irq` pushes PC high, PC low, then P without B, sets I and loads the vector `$FFFC - 2n`; the same for every line. `RTI` pulls P (`| B`), then PC low and high, no `+ 1`. `machine_return_interrupt` does exactly that (`test_return_interrupt` compares it with an executed `RTI`). A hook at a handler's first instruction fires after the entry (`find_hook`: the CPU is not waiting, and with I set no interrupt is pending), so `machine_finish_routine` from the hook runs the ROM handler to its `RTI`, where SP rises 3 above the hook's (not 2: `diff_lts`'s unwound test uses 3 for an `isr` row).
- **The SFR state `diff_lts` compares** (`m50734` in `m50734.h`): `port_latch[0-3]`, `port_dir[0-3]`, `icr1`, `icr3`, `icr2 & $15` (the enable bits), `uart_ctrl`, `uart_rx`, `uart_rx_full`, `uart_tx_count`, `uart_tx_last`. `icr2`'s request bits are set by `m50734_tick` as cycles pass, and the C copy runs (almost) none: comparing all of `icr2` was tried while proving the plan and gave **216,954 mismatches** on the existing replacements (`ICR1/ICR2/ICR3: ROM 01/38/00, C 01/18/00`: timer 3's request bit, $20, set every 200 cycles while speaking). With the enable bits only, `diff_lts` prints exactly the call counts it printed before the change and 0 mismatches (Step 5): the comparison change alone moves nothing.
- **`ser_hex_chars`** $C561–$C570: `30 31 … 39 41 … 46`, "0123456789ABCDEF" (16 bytes, no terminating 0: $C571 is `ser_tx_hex`'s first `PHA`). `firmware_data`: 48,496 + 16 = **48,512**. `ghidra740/annotations/serial.txt` names it (`char[16]`).
- **The callers of the 20 routines** (the scan of every `JSR`/`JMP` operand and of the vectors $FFE0–$FFFF; recorded in `ser_addr.h`): `isr_int1` only `vec_int1_serial` $FFFA; `isr_int4_host_line` only `vec_int4_timerx` $FFF4; `ser_rx_byte` $C32E, $C356, $C36F; `ser_rx_put` $C38D, $C3FF, $C409, $C622 (`boot_queue_string`); `isr_host_line_high` $AC74, $C3E7; `isr_host_line_low` $AC7A, $C3E3; `ser_rx_flush_cmd` $C446, $C48F; `cmd_imm_match` $C3A8; `cmd_imm_done` $C46C by `JMP` $C449, $C492, $C4B2; the two handlers by no operand (only `JMP (cmd_imm_vector)`); `ser_tx_get` $C30A, $C58A; `ser_tx_put` $AB99, $C497, $C4A9, $C578, $C57C, $C5AB, $C5BE, $C5CD, $C643 ($AB99 and $C643 are the ROM `cmd_echo` and `cmd_reply_setting`, C since M4.2); `ser_tx_send` $C58D; `ser_hex_digits` $C574; `ser_hex_digit` $C542, $C54F; `ser_tx_hex` $C49C, $C5B0, $C5B5, $C650; `ser_tx_service` $A6D7, $B89C; `ser_tx_records` $ABCD; `ser_rx_next_page` $A6F5, $C3D9; `ser_tx_next_page` $C4C6, $C4F0. The byte before every entry is an `RTS` ($60), an `RTI` ($40), the operand of a `JMP` ($C4 before $C495 and $C4B5) or data ($46 before $C571, the last hex digit): no routine is entered by falling through.
- **What the corpus never enters** (`apollo2_coverage`, spec §4.4, re-checked): `ser_tx_get`, `ser_tx_send`, `ser_tx_service`, `ser_tx_next_page`, `isr_int4_host_line`, `isr_host_line_high` (and `ser_tx_wait`). - **The boot state of the serial SFRs** (`boot_init_ports`, `boot_init_host_lines`, serial mode): P0_DIR $78 (P0.0, P0.1, P0.2 and P0.7 inputs), P0 latch $20, then P0_FUNC $4C, UART_CTRL $D1; ICR3 = $48 (`isr_host_line_low`, the host line being low); `boot_clear_input_state` sets both ring pointers ($2100 and $3900), clears the counts and flags and sets `cmd_index_reset` = 1. #include <stdio.h>
```c
#include <string.h>
#include "diff_state.h"
#include "engine/thunks.h"

#define ICR2_ENABLES 0x15   /* timers 1-3: enable bits 0, 2, 4 */

const char *const diff_probed[] = {
    "ser_tx_get", "ser_tx_send", "ser_tx_service", "ser_tx_next_page", "isr_int4_host_line", "isr_host_line_high",
};
const size_t diff_probed_count = sizeof diff_probed / sizeof diff_probed[0];

bool diff_is_probed(const char *name)
{
    for (size_t i = 0; i < diff_probed_count; i++)
        if (!strcmp(diff_probed[i], name))
            return true;
    return false;
}

static bool sfr_same(const m50734 *a, const m50734 *b, char *why, size_t n)
{
    for (int p = 0; p < 4; p++) {
        if (a->port_latch[p] != b->port_latch[p] || a->port_dir[p] != b->port_dir[p]) {
            snprintf(why, n, "P%d latch/dir: ROM %02X/%02X, C %02X/%02X", p, a->port_latch[p], a->port_dir[p],
                     b->port_latch[p], b->port_dir[p]);
            return false;
        }
    }
    if (a->icr1 != b->icr1 || ((a->icr2 ^ b->icr2) & ICR2_ENABLES) || a->icr3 != b->icr3) {
        snprintf(why, n, "ICR1/ICR2/ICR3: ROM %02X/%02X/%02X, C %02X/%02X/%02X", a->icr1, a->icr2, a->icr3, b->icr1,
                 b->icr2, b->icr3);
        return false;
    }
    if (a->uart_ctrl != b->uart_ctrl || a->uart_rx != b->uart_rx || a->uart_rx_full != b->uart_rx_full) {
        snprintf(why, n, "UART ctrl/rx/full: ROM %02X/%02X/%d, C %02X/%02X/%d", a->uart_ctrl, a->uart_rx,
                 a->uart_rx_full, b->uart_ctrl, b->uart_rx, b->uart_rx_full);
        return false;
    }
    if (a->uart_tx_count != b->uart_tx_count || a->uart_tx_last != b->uart_tx_last) {
        snprintf(why, n, "UART TX: ROM %u/%02X, C %u/%02X", (unsigned)a->uart_tx_count, a->uart_tx_last,
                 (unsigned)b->uart_tx_count, b->uart_tx_last);
        return false;
    }
    return true;
}

bool diff_same(const machine *a, const machine *b, uint8_t outputs, char *why, size_t n)
{
    if (a->cpu.pc != b->cpu.pc || a->cpu.s != b->cpu.s) {
        snprintf(why, n, "exit PC/S: ROM %04X/%02X, C %04X/%02X", a->cpu.pc, a->cpu.s, b->cpu.pc, b->cpu.s);
        return false;
    }
    if ((outputs & FW_OUT_A) && a->cpu.a != b->cpu.a) {
        snprintf(why, n, "A: ROM %02X, C %02X", a->cpu.a, b->cpu.a);
        return false;
    }
    if ((outputs & FW_OUT_X) && a->cpu.x != b->cpu.x) {
        snprintf(why, n, "X: ROM %02X, C %02X", a->cpu.x, b->cpu.x);
        return false;
    }
    if ((outputs & FW_OUT_Y) && a->cpu.y != b->cpu.y) {
        snprintf(why, n, "Y: ROM %02X, C %02X", a->cpu.y, b->cpu.y);
        return false;
    }
    if ((outputs & FW_OUT_Z) && ((a->cpu.p ^ b->cpu.p) & CPU740_Z)) {
        snprintf(why, n, "Z: ROM %d, C %d", (a->cpu.p & CPU740_Z) != 0, (b->cpu.p & CPU740_Z) != 0);
        return false;
    }
    if (!sfr_same(&a->sfr, &b->sfr, why, n))
        return false;
    for (uint32_t addr = 0; addr < MACHINE_RAM_SIZE; addr++) {
        if (addr >= M50734_SFR_FIRST && addr <= 0xFF)
            continue;
        if (addr >= 0x100 && addr <= 0x100u + a->cpu.s)
            continue;   /* the dead stack below the exit SP */
        if (a->ram[addr] != b->ram[addr]) {
            snprintf(why, n, "RAM $%04X: ROM %02X, C %02X", (unsigned)addr, a->ram[addr], b->ram[addr]);
            return false;
        }
    }
    return true;
}
```

```c
   of the SFR reads and writes and of the waits, so that the order of every access is pinned, and that fails every
   ROM call (the serial code makes none). Each expected value is worked out from the dump of the routine
   (build/ghidra740/dump), as the comment beside it says. The full proof is the live differential tests (diff_lts,
   diff_serial) and the hybrid goldens (golden_hybrid). */
#include <string.h>
#include "test.h"
#include "firmware/fw.h"
#include "firmware/data/fw_data.h"

#define MAX_LOG     256
#define SFR_P0      0xF6
#define SFR_ICR1    0xFF

typedef enum { LOG_READ, LOG_WRITE, LOG_WAIT } log_kind;
typedef struct { log_kind kind; uint8_t addr, value; } log_entry;

static uint8_t g_ram[0x10000];   /* the firmware's RAM is $0000-$3FFF; 64 KiB so no index can run off the array */
static fw g_f;
static fw_host g_host;
static uint8_t g_sfr[0x100];     /* the stub's SFRs: a read returns g_sfr[addr], a write sets it */
static log_entry g_log[MAX_LOG];
static unsigned g_nlog, g_ncalls;
static bool g_wait_ok;           /* what the stub's wait returns */
static uint8_t g_script_addr;    /* reads of this SFR take the next g_script value while any is left (a level that */
static uint8_t g_script[8];      /* changes between two reads), storing it in g_sfr; 0 = no script */
static unsigned g_script_n, g_script_pos;

static void log_add(log_kind kind, uint8_t addr, uint8_t value)
{
    if (g_nlog < MAX_LOG)
        g_log[g_nlog] = (log_entry){ kind, addr, value };
    g_nlog++;
}

static uint8_t stub_read_sfr(void *ctx, uint8_t addr)
{
    (void)ctx;
    if (g_script_addr && addr == g_script_addr && g_script_pos < g_script_n)
        g_sfr[addr] = g_script[g_script_pos++];
    log_add(LOG_READ, addr, g_sfr[addr]);
    return g_sfr[addr];
}

static void stub_write_sfr(void *ctx, uint8_t addr, uint8_t value)
{
    (void)ctx;
    g_sfr[addr] = value;
    log_add(LOG_WRITE, addr, value);
}

static bool stub_wait(void *ctx, fw_wait_kind kind)
{

    log_add(LOG_WAIT, (uint8_t)kind, 0);
    return g_wait_ok;
}

    (void)addr;
    (void)r;
    (void)budget;
```

```c
#define PROBE_COUNT (sizeof g_probes / sizeof g_probes[0])

/* Copy A, at the probe's destination: the branch was the last instruction executed (or there is none). */
static bool on_dest(machine *m, void *user)
{
    (void)user;
    if (!g_cur->branch || m->history[(m->history_pos - 1) % MACHINE_HISTORY] == g_cur->branch)
        g_hit = true;
    return false;
}

/* Runs the probe's routine in m: an interrupt handler to its RTI, a subroutine through machine_rom_call. With b, the
   routine's replacement is hooked first (copy B). */
static bool run_copy(machine *m, const probe *p, fw_bridge *b)
{
    if (b && (!fw_bridge_init(b, m) || !fw_install(m, b, p->routine)))
        return false;
    if (p->isr)
        return machine_finish_routine(m, PROBE_BUDGET);
    machine_regs r = { m->cpu.a, m->cpu.x, m->cpu.y, m->cpu.p };
    return machine_rom_call(m, p->addr, &r, PROBE_BUDGET) == MCALL_RETURNED;
}

static void check_probe(machine *m, probe *p)
{
    char why[160] = "";
    unsigned call = p->calls++;
    machine_clone(&g_a, m);
    machine_hold_irqs(&g_a, true);
    p->inject(&g_a);
    machine_clone(&g_b, m);
    machine_hold_irqs(&g_b, true);
    p->inject(&g_b);
    g_cur = p;
    g_hit = false;
    CHECK(machine_hook(&g_a, p->dest, on_dest, NULL));
    bool a_ok = run_copy(&g_a, p, NULL);
    p->reached += g_hit;
    bool use_c = !g_self_check && fw_replacement_find(p->routine) != NULL;
    bool b_ok = run_copy(&g_b, p, use_c ? &g_bridge : NULL);
    if (!a_ok)
        snprintf(why, sizeof why, "the ROM routine did not return (fault %d)", (int)g_a.fault);
    else if (!b_ok)
        snprintf(why, sizeof why, "copy B did not return (fault %d at $%04X)", (int)g_b.fault, g_b.fault_addr);
    else if (diff_same(&g_a, &g_b, REGS, why, sizeof why))
        why[0] = '\0';
    if (why[0] && g_mismatches++ < 10)
        fprintf(stderr, "  %s: %s call %u (A=%02X X=%02X Y=%02X): %s\n", g_source, p->name, call, m->cpu.a, m->cpu.x,
                m->cpu.y, why);
}

static void check_point(machine *m, probe_point at)
{
    for (size_t i = 0; i < PROBE_COUNT; i++)
        if (g_probes[i].at == at)
            check_probe(m, &g_probes[i]);
}

static bool on_int1(machine *m, void *user)
{
    (void)user;
    check_point(m, AT_INT1);
    return false;   /* the ROM routine runs on in m */
}

static bool on_tx_put(machine *m, void *user)
{
    (void)user;
    check_point(m, AT_TX_PUT);
    return false;
}

static void install(machine *m, void *user)
{
    (void)user;
    CHECK(machine_hook(m, ROM_ISR_INT1, on_int1, NULL));
    CHECK(machine_hook(m, ROM_SER_TX_PUT, on_tx_put, NULL));
}

static void run(const uint8_t *rom, size_t len, const char *source, const char *text, bool boot)
{
    frame_list fl = { 0 };
    g_source = source;
    machine_status st = rom_engine_run(&g_m, rom, len, NULL, install, NULL, text, boot, &fl, NULL);
    if (st != MACHINE_IDLE)
        machine_dump(&g_m, stderr);
    CHECK_EQ(st, MACHINE_IDLE);
    machine_clear_hooks(&g_m);
    frame_list_free(&fl);
}

static void strip_newline(char *s)
{
    size_t n = strlen(s);
    while (n > 0 && (s[n - 1] == '\n' || s[n - 1] == '\r'))
        s[--n] = '\0';
}

static void run_file(const uint8_t *rom, size_t len, const char *name)

    snprintf(path, sizeof path, "tests/corpus/%s.txt", name);
    char *text = test_read_file(path);
    CHECK(text != NULL);

}

/* Prints each probe's counts; every probe compared and its target reached at least once. */
static void report(void)
{
    for (size_t i = 0; i < PROBE_COUNT; i++) {
        const probe *p = &g_probes[i];
        bool c = !g_self_check && fw_replacement_find(p->routine) != NULL;
        if (p->branch)
            printf("  %-16s %-18s %5u calls compared (%s), $%04X -> $%04X in %u\n", p->name, p->routine, p->calls,
                   c ? "C" : "ROM", p->branch, p->dest, p->reached);
        else
            printf("  %-16s %-18s %5u calls compared (%s), entered in %u\n", p->name, p->routine, p->calls,
                   c ? "C" : "ROM", p->reached);

        CHECK(p->reached > 0);
    }
}
```

```c
#define SER_CR            0x0D   /* ser_tx_records' last byte */

/* ---- the reply output ---- */

void ser_tx_next_page(fw *f, fw_regs *r)
{
    (void)f;
    r->y++;                                                      /* INY */
    if (r->y == SER_TX_PAGE + 1)                                 /* CPY #$3A */
        r->y = SER_TX_PAGE;
}

/* INC ptr; BNE; LDY ptr+1; JSR ser_tx_next_page; STY ptr+1 ($C4C0-$C4C9, $C4EA-$C4F3): the output ring pointer at
   ptr moves on; at a page end Y = the new page. */
static void tx_step(fw *f, uint16_t ptr, fw_regs *r)
{
    uint8_t lo = (uint8_t)(fw_rd8(f, ptr) + 1);
    fw_wr8(f, ptr, lo);
    if (lo != 0)
        return;
    r->y = fw_rd8(f, (uint16_t)(ptr + 1));
    ser_tx_next_page(f, r);
    fw_wr8(f, (uint16_t)(ptr + 1), r->y);
}

{
    r->a = SER_NAK;                                              /* $C4B5-$C4B7: PHP, SEI, LDA #$15 */
    if (fw_rd8(f, SER_TX_PENDING) & 1) {                         /* BBC0 ser_tx_pending */
        r->y = 0;
        r->a = fw_ind_y(f, (uint8_t)SER_TX_READ, 0);             /* LDA (ser_tx_read),Y */
        tx_step(f, SER_TX_READ, r);
        r->y = fw_rd8(f, SER_TX_COUNT);                          /* $C4CB: tested before the DEY */
        if (r->y != 0) {
            r->y--;
            fw_wr8(f, SER_TX_COUNT, r->y);
            if (r->y != 0)
                return;                                          /* PLP, RTS */
        }
    }
    fw_wr8(f, SER_TX_PENDING, 0);                                /* $C4D7 LDM #0 */
}

void ser_tx_put(fw *f, fw_regs *r)
{
    fw_regs t = *r;                                              /* PHA / TXA / PHA / TYA / PHA ... PLA: kept */
    fw_wr_ind_y(f, (uint8_t)SER_TX_WRITE, 0, r->a);              /* LDA $0103,X (the pushed A); STA (ser_tx_write),Y */
    t.y = 0;
    tx_step(f, SER_TX_WRITE, &t);
    fw_inc8(f, SER_TX_COUNT);
    fw_wr8(f, SER_TX_PENDING, 1);                                /* LDM #1 */
}

void ser_tx_send(fw *f, fw_regs *r)
{
    fw_wait(f, FW_WAIT_UART_TX);                                 /* $C505 JSR ser_tx_wait (inside PHP ... PLP) */
    fw_wr_sfr8(f, SFR_UART_TX, r->a);                            /* $C508 STA UART_TX */
}

void ser_hex_digit(fw *f, fw_regs *r)
{
    r->y = r->a & 0x0F;                                          /* AND #$0F; TAY */
    r->a = fw_rom8(f, (uint16_t)(SER_HEX_CHARS + r->y));         /* LDA ser_hex_chars,Y */
}

void ser_hex_digits(fw *f, fw_regs *r, uint8_t pair[2])
{
    fw_regs t = *r;                                              /* TXA / PHA / TYA / PHA ... PLA / TAY / PLA / TAX */
    t.a = pair[0];                                               /* LDA $0105,X */
    ser_hex_digit(f, &t);
    pair[0] = t.a;
    t.a = (uint8_t)(pair[1] >> 4);                               /* LDA $0106,X; LSR A x4 */
    ser_hex_digit(f, &t);
    pair[1] = t.a;
    r->a = r->x;
}

void ser_tx_hex(fw *f, fw_regs *r)
{
    uint8_t pair[2] = { r->a, r->a };                            /* PHA x3: the last two become the digits */
    fw_regs t = *r;
    ser_hex_digits(f, &t, pair);
    t.a = pair[0];                                               /* PLA: the low nibble's digit first */
    ser_tx_put(f, &t);
    t.a = pair[1];
    ser_tx_put(f, &t);                                           /* the last PLA: A as it came */
}

void ser_tx_service(fw *f, fw_regs *r)
{
    if (fw_rd8(f, BOOT_DIP) & 1)                                 /* $C582 BBS0 boot_dip: parallel mode */
        return;
    if (!fw_sfr_bit(f, SFR_P0, P0_HOST_LINE))                    /* $C585 BBC2 P0: the host line low */
        return;
    fw_sfr_clb(f, SFR_P0, P0_BUSY);                              /* CLB5 P0 */
    fw_regs t = *r;
    ser_tx_get(f, &t);
    ser_tx_send(f, &t);
    uint8_t pending = fw_rd8(f, SER_TX_PENDING);                 /* LDA ser_tx_pending */
    fw_wr8(f, SER_STATUS_DUE, pending);
    if (pending == 0) {                                          /* BNE: the whole byte */
        fw_wait(f, FW_WAIT_UART_TX);                             /* $C596 JSR ser_tx_wait */
        if (fw_sfr_bit(f, SFR_P0, P0_HOST_LINE))                 /* PHP, SEI, BBC2 P0 */
            fw_sfr_seb(f, SFR_P0, P0_BUSY);                      /* SEB5 P0 */
    }
    r->y = t.y;                                                  /* $C5A2 PLA: A as it came */
}

void ser_tx_records(fw *f, fw_regs *r)
{
    fw_regs t = *r;                                              /* PHA / TXA / PHA / TYA / PHA ... PLA: kept */
    t.a = fw_rd8(f, SER_REPLY_ID);
    ser_tx_put(f, &t);
    t.a = fw_rd8(f, SER_REPLY_COUNT);
    ser_tx_hex(f, &t);
    t.a = fw_rd8(f, SER_REPLY_SIZE);
    ser_tx_hex(f, &t);
    t.y = 0;
    uint8_t n;
    do {
        t.x = fw_rd8(f, SER_REPLY_SIZE);                         /* $C5BA LDX ser_reply_size */
        do {
            t.a = fw_ind_y(f, (uint8_t)SER_REPLY_PTR, t.y);      /* LDA (ser_reply_ptr),Y */
            ser_tx_put(f, &t);
            t.y++;
            t.x--;
        } while (t.x != 0);                                      /* DEX; BNE */
        n = (uint8_t)(fw_rd8(f, SER_REPLY_COUNT) - 1);           /* $C5C5 LDX ser_reply_size; DEC ser_reply_count */
        fw_wr8(f, SER_REPLY_COUNT, n);
    } while (n != 0);
    t.a = SER_CR;
    ser_tx_put(f, &t);
}
```

```c
#define FW_SER_H
/* The serial code's receive path and reply output (ROM $C37E-$C3DE, $C3FA-$C412, $C4B5-$C5FD), decompiled (M4.6a
   spec 2.1, 2.2, 2.6). Each routine takes the registers at entry in r and leaves in r the A, X and Y the ROM leaves
   at its RTS; r->p is not used: no caller reads a flag, and the PHP/SEI ... PLP pairs only hold interrupts off,
   which the C, taking no emulated time, needs no more. SFRs are read and written through the host in the ROM's
   order (fw_sfr*), and the UART wait goes through the host too (fw_wait). */
#include "fw.h"

/* The SFRs of the serial code (M4.6a spec 2.5; ghidra740/annotations/sfr.txt) */
#define SFR_UART_TX      0xE4
#define SFR_UART_RX      0xE5
#define SFR_UART_CTRL    0xE6   /* bit 4: receive interrupt enable */
#define SFR_UART_STATUS  0xE7   /* bit 1: transmitter ready; bits 2-4: receive errors */
#define SFR_P1_LATCH     0xF2   /* the parallel data byte (an input latch) */
#define SFR_P1           0xF3
#define SFR_P1_DIR       0xF4
#define SFR_P0           0xF6
#define SFR_ICR3         0xFD   /* bits 6/7: INT4 enable/request */
#define SFR_ICR1         0xFF   /* bits 0/1: _INT1 enable/request */
#define P0_HOST_LINE     2      /* P0.2: the host's handshake line (an input) */
#define P0_BUSY          5      /* P0.5: the busy line to the host */

#define SER_NAK          0x15   /* ser_tx_get's answer when nothing is pending */

/* $C5F5: Y = the next page of the output ring, Y + 1 with $3A wrapping to $39 (the ring is the one page $3900);
   A and X kept. */
void ser_tx_next_page(fw *f, fw_regs *r);
/* $C4B5: A = the reply byte at ser_tx_read, which moves on (ser_tx_next_page at a page end); ser_tx_count is tested
   before it is counted down, and ser_tx_pending = 0 when it was or becomes 0. Y = the new count (0 when it was 0).
   With ser_tx_pending bit 0 clear: A = NAK, ser_tx_pending = 0, Y kept. X kept. */
void ser_tx_get(fw *f, fw_regs *r);
/* $C4DD: A at ser_tx_write, which moves on; ser_tx_count + 1, ser_tx_pending = 1. A, X and Y kept (the ROM reads
   its byte back from the stack, LDA $0103,X after TSX: the A it pushed). */
void ser_tx_put(fw *f, fw_regs *r);
/* $C504: waits for the UART (FW_WAIT_UART_TX), then sends A (UART_TX); A, X and Y kept. */
void ser_tx_send(fw *f, fw_regs *r);
/* $C55A: A = the hex digit of A & $0F (ser_hex_chars), Y = A & $0F; X kept. */
void ser_hex_digit(fw *f, fw_regs *r);
/* $C53A: the two bytes its caller pushed last become hex digits in place: pair[0] (LDA $0105,X after its TSX: the
   last push) the digit of its low nibble, pair[1] ($0106,X) the digit of its high nibble. A = X; X and Y kept. */
void ser_hex_digits(fw *f, fw_regs *r, uint8_t pair[2]);
/* $C571: A as two hex digits, the low nibble's first (ser_hex_digits on two copies of A, then ser_tx_put of each);
   A, X and Y kept. */
void ser_tx_hex(fw *f, fw_regs *r);
/* $C581: in serial mode (boot_dip bit 0 clear) with the host line P0.2 high: the busy line P0.5 cleared, one reply
   byte sent (ser_tx_get, ser_tx_send) and ser_status_due = ser_tx_pending; when that is 0, after the UART is ready
   again, P0.5 set if P0.2 is still high. A and X kept; Y as ser_tx_get leaves it when it ran. */
void ser_tx_service(fw *f, fw_regs *r);
/* $C5A4: a record reply: ser_reply_id, then ser_reply_count and ser_reply_size in hex, then ser_reply_count records
   of ser_reply_size bytes from ser_reply_ptr, then CR; ser_reply_count is counted down to 0. A, X and Y kept. */
void ser_tx_records(fw *f, fw_regs *r);
```

```c
/* The zero page cmd_imm_match keeps for the command scan it may interrupt, in push order ($C418-$C42C; pulled in
   reverse at cmd_imm_done $C46C-$C47F): cmd_table_ofs, cmd_table_ptr, cmd_text_ptr, cmd_pat_ptr. */
static const uint8_t k_kept[] = {
    CMD_TABLE_OFS, CMD_TABLE_PTR, CMD_TABLE_PTR + 1, CMD_TEXT_PTR, CMD_TEXT_PTR + 1, CMD_PAT_PTR, CMD_PAT_PTR + 1,
};

void cmd_imm_match(fw *f, fw_regs *r)
{
    uint8_t kept[sizeof k_kept];
    fw_wr_ind_y(f, (uint8_t)SER_CMD_PTR, 0, r->a);               /* PHA; LDY #0; STA (ser_cmd_ptr),Y */
    for (size_t i = 0; i < sizeof k_kept; i++)
        kept[i] = fw_rd8(f, k_kept[i]);
    fw_wr8(f, CMD_TABLE_OFS, fw_rd8(f, SER_CMD_TABLE_OFS));      /* $C42D */
    fw_wr16(f, CMD_TEXT_PTR, SER_CMD_BUF);
    fw_wr16(f, CMD_TABLE_PTR, CMD_IMM_TABLE);
    fw_regs t = *r;
    t.y = cmd_match_table(f);                                    /* X kept */
    if (t.y == 0) {                                              /* $C440 CPY #0; BNE: no match */
        fw_clb(f, SER_CMD_MODE, 0);
        t.a = 0xFF;                                              /* cmd_match_table's A at the end marker */
        ser_rx_flush_cmd(f, &t);
    } else if (fw_ind_y(f, (uint8_t)CMD_PAT_PTR, t.y) != 0) {    /* $C44C LDA (cmd_pat_ptr),Y; BEQ: partial */
        t.y = fw_rd8(f, CMD_TABLE_OFS);
        fw_wr8(f, SER_CMD_TABLE_OFS, t.y);
        uint8_t lo = (uint8_t)(fw_rd8(f, SER_CMD_PTR) + 1);      /* INC ser_cmd_ptr; BNE; INC ser_cmd_ptr+1 */
        fw_wr8(f, SER_CMD_PTR, lo);
        if (lo == 0)
            fw_inc8(f, SER_CMD_PTR + 1);
    } else {                                                     /* $C45C: a full match */
        uint16_t handler = (uint16_t)(fw_ind_y(f, (uint8_t)CMD_PAT_PTR, (uint8_t)(t.y + 1)) |
                                      fw_ind_y(f, (uint8_t)CMD_PAT_PTR, (uint8_t)(t.y + 2)) << 8);
        fw_wr16(f, CMD_IMM_VECTOR, handler);
        t.y = 0;
        t.a = fw_ind_y(f, (uint8_t)SER_CMD_PTR, 0);              /* $C468 LDA (ser_cmd_ptr),Y */
        switch (handler) {                                       /* $C46A JMP (cmd_imm_vector) */
        case ROM_CMD_IMM_INDEX_ADD:
            cmd_imm_index_add(f, &t);
            break;
        case ROM_CMD_IMM_INDEX_QUERY:
            cmd_imm_index_query(f, &t);
            break;
        default:
            fw_fault(f, handler);
            break;
        }
    }
    for (size_t i = sizeof k_kept; i-- > 0;)                     /* cmd_imm_done */
        fw_wr8(f, k_kept[i], kept[i]);
    r->y = t.y;                                                  /* $C481 PLA: A as it came; X kept */
}

void cmd_imm_index_add(fw *f, fw_regs *r)
{
    if (fw_rd8(f, CMD_INDEX_RESET) & 1) {                        /* BBC0 cmd_index_reset */
        fw_wr8(f, CMD_INDEX_COUNT, 0);
        fw_clb(f, CMD_INDEX_RESET, 0);
    }
    fw_inc8(f, CMD_INDEX_COUNT);
    fw_clb(f, SER_CMD_MODE, 0);
    ser_rx_flush_cmd(f, r);
}

void cmd_imm_index_query(fw *f, fw_regs *r)
{
    r->a = 'I';
    ser_tx_put(f, r);
    r->a = fw_rd8(f, CMD_INDEX_COUNT);
    ser_tx_hex(f, r);
    r->a = 'T';                                                  /* text waiting or speech in progress */

        r->a = 'M';                                              /* $C4A7: neither */
    ser_tx_put(f, r);
    fw_clb(f, SER_CMD_MODE, 0);
    r->a = fw_rd8(f, SER_RX_IDLE_SAVED);
    fw_wr8(f, SER_RX_IDLE, r->a);
}
```

```c
#define FW_CMD_IMM_H
/* The immediate commands (ROM $C413-$C4B4), decompiled (M4.6a spec 2.1, 2.6): matched at interrupt level byte by
   byte as they arrive, and run at once. Each routine takes the registers at entry in r and leaves in r the A, X and
   Y the ROM leaves; r->p is not used. */
#include "fw.h"
```

```c
#include "isr_serial.h"
#include "fw_ops.h"
#include "ser.h"

#define UART_ERRORS      0x1C   /* UART_STATUS bits 2-4 */
#define UART_RX_IRQ      4      /* UART_CTRL bit 4: the receive interrupt */
#define ICR1_INT1_EN     0      /* ICR1: the _INT1 enable and request bits */
#define ICR1_INT1_REQ    1
#define ICR3_INT4_EN     6      /* ICR3: the INT4 enable and request bits */
#define ICR3_INT4_REQ    7
#define ICR3_HOST_HIGH   0x40
#define ICR3_HOST_LOW    0x48
#define P0_ACK           0      /* P0.0: the host's acknowledge (parallel mode) */
#define P0_READY         3      /* P0.3: ready for the next host byte */
#define P0_STROBE        4      /* P0.4: the host's strobe (parallel mode) */
#define PAR_REPLY_CODE   5      /* P1_LATCH: the host asks for a reply byte */
#define PAR_DATA_MIN     7      /* P1_LATCH: a data byte from here on */

/* ser_int1_serial $C33C-$C37D, ser_int1_latch $C367: PHA / TXA / PHA / TYA / PHA ... PLA / TAY / PLA / TAX / PLA. */
static void int1_serial(fw *f, const fw_regs *r)
{
    fw_regs t = *r;
    if (fw_sfr_bit(f, SFR_ICR1, ICR1_INT1_REQ)) {                /* BBS1 ICR1: ser_int1_latch */
        t.a = fw_sfr8(f, SFR_P1_LATCH);
        fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_EN);
        fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_REQ);
        ser_rx_byte(f, &t);                                      /* PHP; CLI ... PLP; NOP */
        fw_sfr_seb(f, SFR_ICR1, ICR1_INT1_EN);
    } else {
        fw_sfr_clb(f, SFR_UART_CTRL, UART_RX_IRQ);
        fw_sfr_seb(f, SFR_P0, P0_BUSY);
        fw_sfr_clb(f, SFR_ICR3, ICR3_INT4_EN);
        fw_sfr_clb(f, SFR_ICR3, ICR3_INT4_REQ);
        if (!(fw_sfr8(f, SFR_UART_STATUS) & UART_ERRORS)) {      /* AND #$1C; BNE */
            t.a = fw_sfr8(f, SFR_UART_RX);
            ser_rx_byte(f, &t);                                  /* PHP; CLI ... PLP; NOP */
        }
        fw_sfr_seb(f, SFR_ICR3, ICR3_INT4_EN);                   /* $C35B */
        fw_wr_sfr8(f, SFR_UART_RX, fw_sfr8(f, SFR_UART_RX));     /* LDA UART_RX; STA UART_RX */
        fw_sfr_seb(f, SFR_UART_CTRL, UART_RX_IRQ);
        fw_sfr_clb(f, SFR_P0, P0_BUSY);
    }
    fw_sfr_clb(f, SFR_P0, P0_READY);                             /* $C37B */
}

/* $C2BA-$C33B: parallel mode. */
static void int1_parallel(fw *f, const fw_regs *r)
{
    if (fw_sfr_bit(f, SFR_P0, P0_ACK)) {                         /* BBC0 P0: $C2BD */
        fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_REQ);
        return;
    }
    if (!fw_sfr_bit(f, SFR_P0, P0_STROBE)) {                     /* BBS4 P0 */
        bool done = (fw_rd8(f, ISR_PAR_STATE) & 1) != 0;         /* BBS0 isr_par_state */
        fw_wr_sfr8(f, SFR_P1, 0);
        fw_wr_sfr8(f, SFR_P1_DIR, 0xFF);
        if (!done) {                                             /* $C2C6 */
            fw_sfr_clb(f, SFR_P0, P0_READY);
            fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_REQ);
            fw_sfr_seb(f, SFR_P0, P0_READY);
        } else {                                                 /* $C2D6 */
            fw_clb(f, ISR_PAR_STATE, 0);
            fw_sfr_clb(f, SFR_P0, P0_READY);
            fw_wr_sfr8(f, SFR_P1_LATCH, 0);
            fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_REQ);
        }
        fw_wr_sfr8(f, SFR_P1_DIR, 0);
        return;
    }
    fw_regs t = *r;                                              /* $C2E9 */
    fw_sfr_clb(f, SFR_P0, P0_READY);
    fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_REQ);
    fw_wr_sfr8(f, SFR_P1, 1);
    fw_wr_sfr8(f, SFR_P1_DIR, 0xFF);
    fw_sfr_clb(f, SFR_ICR1, ICR1_INT1_EN);                       /* after PHA ... PHP; then CLI */
    t.a = fw_sfr8(f, SFR_P1_LATCH);
    if (t.a >= PAR_DATA_MIN) {                                   /* CMP #7; BCS $C315 */
        if (!(fw_rd8(f, ISR_PAR_STATE) & 1)) {                   /* BBS0 isr_par_state */
            t.y = t.a;                                           /* TAY */
            uint8_t ack = (uint8_t)(t.a ^ 0x01);
            fw_wr8(f, ISR_PAR_STATE, 1);
            if (fw_rd8(f, SER_TX_PENDING) & 1) {                 /* BBC0 ser_tx_pending */
                fw_wr8(f, ISR_PAR_STATE, 3);
                ack ^= 0x02;
            }
            fw_wr_sfr8(f, SFR_P1, ack);
            fw_wr_sfr8(f, SFR_P1_DIR, 0xFF);
            fw_sfr_seb(f, SFR_P0, P0_READY);
            t.a = t.y;                                           /* TYA */
            ser_rx_byte(f, &t);
        }
    } else if (t.a == PAR_REPLY_CODE) {                          /* CMP #5; BNE */
        fw_clb(f, ISR_PAR_STATE, 1);
        fw_seb(f, ISR_PAR_STATE, 0);
        ser_tx_get(f, &t);
        fw_wr_sfr8(f, SFR_P1, t.a);
        fw_wr_sfr8(f, SFR_P1_DIR, 0xFF);
    }
    fw_sfr_seb(f, SFR_ICR1, ICR1_INT1_EN);                       /* $C331: SEI; SEB0 ICR1; PLP ... PLA */
}

void isr_int1(fw *f, fw_regs *r)
{
    if (fw_rd8(f, BOOT_DIP) & 1)                                 /* BBS0 boot_dip */
        int1_parallel(f, r);
    else
        int1_serial(f, r);                                       /* JMP ser_int1_serial */
}

void isr_int4_host_line(fw *f, fw_regs *r)
{
    fw_regs t = *r;
    if (fw_sfr_bit(f, SFR_P0, P0_HOST_LINE))                     /* BBS2 P0 */
        isr_host_line_high(f, &t);
    else
        isr_host_line_low(f, &t);
}

void isr_host_line_high(fw *f, fw_regs *r)
{
    (void)r;
    fw_wr_sfr8(f, SFR_ICR3, ICR3_HOST_HIGH);
    fw_sfr_seb(f, SFR_P0, P0_BUSY);
    fw_wr8(f, SER_STATUS_DUE, 1);
}

void isr_host_line_low(fw *f, fw_regs *r)
{
    (void)r;
    fw_wr_sfr8(f, SFR_ICR3, ICR3_HOST_LOW);
    fw_sfr_clb(f, SFR_P0, P0_BUSY);
}
```

**Create `src/firmware/isr_serial.h`:**

```c
#ifndef FW_ISR_SERIAL_H
#define FW_ISR_SERIAL_H
/* The serial interrupt handlers (ROM $C2B4-$C37D, $C3E0-$C3F9), decompiled (M4.6a spec 2.1, 2.3). isr_int1 and
   isr_int4_host_line are entered by the CPU through their vectors and end with RTI; every path leaves A, X and Y as
   they came (the paths that call a routine push and pull them, the others touch none), so r comes back as it went.
   isr_host_line_high and isr_host_line_low are subroutines (JSR ... RTS) that keep A, X and Y. The C takes no
   emulated time and cannot be interrupted, so the nested interrupts the ROM allows around ser_rx_byte and ser_tx_get
   (PHP, CLI ... SEI, PLP) are taken after the RTI instead: a difference of timing only. */
#include "fw.h"

/* $C2B4 INT1 (vec_int1_serial $FFFA). In serial mode (boot_dip bit 0 clear), ser_int1_serial $C33C: on an _INT1
   request (ICR1 bit 1) the byte on P1_LATCH goes to ser_rx_byte (ser_int1_latch $C367, the _INT1 enable bit 0 off
   meanwhile); otherwise, with the UART receive interrupt (UART_CTRL bit 4) and INT4 (ICR3 bit 6) off and the busy
   line P0.5 set meanwhile, the UART's byte when UART_STATUS has no error bit (2-4); UART_RX is then read and written
   back; P0.3 is cleared at the end. In parallel mode, the host's strobe: P0.0 high clears the _INT1 request and ends;
   P0.4 low releases P1 (and with isr_par_state bit 0 set clears it and P1_LATCH); P0.4 high reads P1_LATCH: 5 asks
   for the next reply byte (ser_tx_get, onto P1), 7 or more is a data byte (P1 = the byte with bit 0 flipped, bits 0
   and 1 when ser_tx_pending bit 0 is set, isr_par_state = 1 or 3, then ser_rx_byte) unless isr_par_state bit 0 is
   set, and anything else is ignored. */
void isr_int1(fw *f, fw_regs *r);
/* $C3E0 INT4 (vec_int4_timerx $FFF4): the host line P0.2 changed. High: isr_host_line_high; low:
   isr_host_line_low. */
void isr_int4_host_line(fw *f, fw_regs *r);
/* $C3EB: ICR3 = $40 (INT4 enabled, its request cleared), the busy line P0.5 set, ser_status_due = 1. */
void isr_host_line_high(fw *f, fw_regs *r);
/* $C3F4: ICR3 = $48, the busy line P0.5 cleared. */
void isr_host_line_low(fw *f, fw_regs *r);

#endif
```
