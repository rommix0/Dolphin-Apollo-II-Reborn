rom      4000  data      tn_char_rules_lo               byte[256]      low bytes of the rule-list pointer per character code (high bytes in tn_char_rules_hi); read by tn_say_char and, for a character without a two-letter rule, by the letter-to-sound routine lts_convert_char; always read with P2.7 clear (ROM, not LOW)
rom      4100  data      tn_char_rules_hi               byte[256]      high bytes of the rule-list pointer per character code (see tn_char_rules_lo); every pointer lies in $477C-$5621
rom      477C  data      tn_rules_ctrl                  char[96]       rule lists of the control codes $00-$1F, one per code in order: a single rule with empty contexts and empty output, then the list end $FF
rom      47DC  data      tn_rules_punct                 char[166]      rule lists of space and the punctuation and symbols $21-$2F, in code order. A rule is: left context (bytes >= $1E, stored nearest character first), a count n (< $1E), n further characters the rule consumes and the right context (bytes >= $1E), an output length m and m phonetic characters; rules are tried in order and $FF ends the list. Of these lists only the apostrophe's (a letter in lts_char_class) goes through the rule matcher (lts_match_list); the others are used only by tn_say_char, whose first rule gives the spoken name
rom      4882  data      tn_rules_digits                char[255]      rule lists of the digits 0-9, in order (format as tn_rules_punct): per digit a rule for the digit standing alone, ordinal-suffix rules that consume the suffix, and a default rule; numbers are therefore spoken digit by digit, with no place values
rom      4981  data      tn_rules_punct2                char[69]       rule lists of the symbols $3A-$40, in code order (format as tn_rules_punct); spoken names for tn_say_char
rom      5010  data      tn_rules_symbols3              char[295]      rule lists of the codes $5B-$60, in code order (format as tn_rules_punct)
rom      5137  data      tn_rules_lower                 char[78]       rule lists of the lower-case letters $61-$7A, one per code: a single empty rule (cmd_case_map upper-cases the text, so they are not normally reached)
rom      5185  data      tn_rules_symbols4              char[55]       rule lists of the codes $7B-$7F, in code order (format as tn_rules_punct)
rom      51BC  data      tn_rules_high                  char[1129]     rule lists of the codes $80-$FF, in code order (format as tn_rules_punct), many of them a single empty rule; the last three bytes are one more empty list that no pointer uses (the two-letter rule lists follow)
